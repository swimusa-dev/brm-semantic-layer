# Golden query set (Phase 6, task 6.1)

25 to 50 questions in three bands, each with certified SQL and expected results.
Band 1: headline numbers matching App 1's cards exactly. Band 2: sliced
aggregates. Band 3: traps (people vs assignment counts, summary-string
splitting, history unavailability per D5, pending-edit disclosure per D4,
brand-limited identities). Populated in task 6.1; the weekly eval job writes
results to productops_semantic.agent_eval_results.
